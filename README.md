# Tobi Alegbe

A static personal website for GitHub Pages. Open `index.html` in a browser to
preview it locally; no build step or dependencies are required.

The site content lives in `index.html` and the styling in `style.css`. The
publications are a curated selection, not an automatically refreshed list;
update them in the HTML as needed. Google Scholar links to the broader list.
Personal contact details and other private CV information are intentionally
not included.
