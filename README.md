# Tobi Alegbe

A static, multi-page personal website for GitHub Pages. Open `index.html` in a
browser (or serve the folder locally, e.g. `python3 -m http.server`) to preview;
no build step or external dependencies are required.

## Structure

- `index.html` — Home page (bio, research themes, selected publications, open-source software, career overview, and public profiles)
- `publications.html` — Full curated list of peer-reviewed articles, preprints, PhD dissertation, and selected talks, with interactive category filters and keyword search
- `cv.html` — Public, print-ready Curriculum Vitae (use the **Print / Save PDF** button for a clean PDF layout)
- `interests.html` — Research interests, life outside the lab, and open-source side projects
- `style.css` — Shared responsive and print stylesheets
- `script.js` — Progressive enhancement for publication filtering/search and CV printing

## Privacy & Maintenance

Personal contact details (email addresses, phone numbers, home address, and
other private CV information) are intentionally excluded. To add or update
entries from your private CV or recent papers, edit the corresponding HTML
sections directly. Google Scholar and ORCID are linked for continuously updated
publication records.
